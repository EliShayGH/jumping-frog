# 🐸 הצפרדע הקופצת (Jumping Frog)

משחק דפדפן מצויר בסגנון מחברת וצבעי מים, שבו עוזרים לצפרדע לכוון חץ זווית ועוצמה, לקפוץ מעלה חבצלת לעלה מעל המים הכחולים, לאסוף מטבעות ולהגיע אל הדגל!

🔗 **למשחק החי (Play Online):**  
👉 [**https://elishaygh.github.io/jumping-frog/**](https://elishaygh.github.io/jumping-frog/)

## 🎮 איך משחקים? (How to Play)

* **הארכת החץ / הגברת עוצמה (`⬆️` או `W` או כפתור `חזק +`):** קפיצה חזקה ורחוקה יותר.
* **קיצור החץ / החלשת עוצמה (`⬇️` או `S` או כפתור `חלש -`):** קפיצה עדינה לעלה קרוב.
* **סיבוב החץ ימינה (`➡️` או `D` או כפתור `ימינה`):** סיבוב החץ עם כיוון השעון לקפיצה נמוכה ומהירה.
* **סיבוב החץ שמאלה (`⬅️` או `A` או כפתור `שמאלה`):** סיבוב החץ נגד כיוון השעון לקפיצה גבוהה.
* **קפיצה (`רווח / Space` או כפתור `🦘 קפוץ!`):** שיגור הצפרדע לכיוון החץ!

## ✨ מה מחכה לכם במשחק?

* **שלבים מאתגרים מעל הבריכה:** עלי חבצלת ירוקים בגדלים ומרחקים משתנים, עלי בונוס צדדיים ועלים צפים בשלבים מתקדמים.
* **מטבעות ודגל המטרה:** אוספים מטבעות של **`1`** ו-**`5`** בדרך, ומגיעים לדגל האדום-לבן כדי לזכות במטבע הגדול של **`10`**!
* **🎨 חנות ועיצוב הצפרדע (3 קטגוריות):**
  * **🐸 צפרדעים:** צפרדע אפורה התחלתית, צפרדע זכר, צפרדע נקבה, צפרדע נסיך וצפרדע מלך.
  * **🎨 צבעים:** אפור סקיצה, ירוק יער, כחול מים, אדום תות, סגול מלכותי וזהב נוצץ.
  * **👑 אביזרים:** כובע מסיבה, משקפי שמש, כובע פיראט, גלימת גיבור וכתר מלכות.
* **📱 התאמה מלאה למחשב, טאבלט וטלפון:** כולל כפתורי מגע גדולים על המסך ושמירה אוטומטית בדפדפן.

## 🛠️ מבנה הפרויקט (Project Structure)

המשחק בנוי בקובץ HTML אחד עצמאי (`index.html`) ללא תלות בספריות חיצוניות, עם ציור וקטורי בצבעי מים ב-HTML5 Canvas וצלילים מסונתזים ב-Web Audio API.

* `index.html` — קוד המשחק המלא (עיצוב, פיזיקה, שלבים, חנות וסאונד).
* `README.md` — מדריך למשחק ולמאגר.
* `HANDOFF.md` — מסמך הקשר טכני להמשך פיתוח עתידי.
